## I Experiment with with Spec-first Test Driven Devlelpment with some new features.

The idea is to (per branch) implment a feature TDD based approach, were we can use AI based on an indepth implementation plan.

We use TDD as a way to have more granular control, as we can explitly test for the functionaility we want rather than hoping the AI does exactly what we mean.

I am experimenting with someone elses thought experiment on this, which is a loose interpretation of Spec Kit development with TDD principles intertwined.
